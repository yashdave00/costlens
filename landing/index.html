CostLens scans any repo for cost leaks — N+1 queries, uncached fetches, heavy deps in serverless bundles, Supabase select("*"), unoptimized images, committed binaries — and emits an agent-ready fix report in seconds.

What it catches
N+1 queries DB calls inside loops multiply with data size. 10–1000× more calls than needed.
Missing cache Uncached fetches hammer your origin and database on every request.
Heavy bundles moment, lodash, puppeteer in client or serverless routes inflate cold starts.
Supabase leaks select("*"), unbounded queries, realtime overuse, untransformed storage URLs.
Image bloat Raw <img> tags and oversized assets in public/.
Repo bloat Committed binaries, secrets, node_modules, and excessive dependencies.
Agent-ready output

Every finding ships with a fix prompt you paste into Claude Code or Cursor to auto-apply. A combined Agent Fix Block sits at the end.
