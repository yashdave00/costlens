What it catches

Six categories of cost leaks.

Each finding includes file:line, estimated savings, and a fix prompt you can paste into Claude Code or Cursor.

🔍

N+1 queries

DB calls inside loops multiply with data size. Batch with .in() or joins.

⚡

Missing cache

Uncached fetches hit your origin and database on every request. Add revalidate or ISR.

📦

Heavy bundles

moment, lodash, and puppeteer in client or serverless routes inflate cold starts.

🗄️

Supabase leaks

select("*"), unbounded queries, realtime overuse, untransformed storage URLs.

🖼️

Image bloat

Raw <img> tags and oversized assets in public/. Cut bandwidth 30 to 70%.

🧹

Repo bloat

Committed binaries, secrets, node_modules, excessive dependencies. Shrink clones and CI.

Agent-ready output

Every finding ships with a fix prompt.

Paste the report into Claude Code or Cursor and it auto-applies the fixes. A combined Agent Fix Block sits at the end.
