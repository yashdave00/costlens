The problem

Vibe-coded apps ship fast.
Cloud bills ship faster.

AI-generated code works. But it's expensive to run. Every uncached fetch, every N+1 query, every heavy bundle adds up.

💸

N+1 queries

10 to 1000x more database calls than needed. Each one costs money on managed databases.

🔥

Uncached fetches

Every request hits your origin and database. No caching means no savings.

📦

Heavy bundles

moment, lodash, puppeteer in serverless routes inflate cold starts and memory.

🗄️

Supabase leaks

select("*") pulls every column. Unbounded queries return huge payloads.

What it catches

Six categories of cost leaks.

Each finding includes file:line, estimated savings, and a fix prompt you can paste into Claude Code or Cursor.

🔍

N+1 queries

DB calls inside loops multiply with data size. Batch with .in() or joins.

⚡

Missing cache

Uncached fetches hit your origin and database on every request. Add revalidate or ISR.

📦

Heavy bundles

moment, lodash, and puppeteer in client or serverless routes inflate cold starts.

🗄️

Supabase leaks

select("*"), unbounded queries, realtime overuse, untransformed storage URLs.

🖼️

Image bloat

Raw <img> tags and oversized assets in public/. Cut bandwidth 30 to 70%.

🧹

Repo bloat

Committed binaries, secrets, node_modules, excessive dependencies. Shrink clones and CI.

FAQ

Common questions.

Does the scanner need access to my production environment?
No. It runs locally on your codebase. Read-only repo access is enough for cloud audits.
What stacks does it support?
Language-agnostic core (npm, pip, go, ruby, php, rust, java) plus deep rules for Next.js, Supabase, and Vercel. Works on any codebase.
How long does a cloud audit take?
Probe audits are delivered within 48 hours. Investigate and Architect tiers include PRs and take 3-5 days.
Is my code safe?
Yes. The scanner runs locally. For cloud audits, you share read-only access or a CSV export. I don't store or share your code.
What if the audit doesn't find savings?
Architect tier has a full refund guarantee if savings are under $200/mo. Lower tiers are priced to be worth it regardless.
Can I run this on a monorepo?
Yes. Point it at any directory. It skips node_modules, .git, and build artifacts automatically.
